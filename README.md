# DataCare Compliance Solutions

A responsive, multi-section business website built with HTML, CSS and vanilla JavaScript.

## Open in VS Code
1. Extract `SteveProject.zip`.
2. Open the `SteveProject` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and choose **Open with Live Server**.

## Customise
- Business details and page content: `index.html`
- Colours, spacing and responsive layout: `style.css`
- Mobile navigation and enquiry form: `script.js`

The enquiry form prepares an email using the visitor's default email app; it does not store submissions or send them to a server. For a live production site, connect it to a secure form service or backend.

Review all professional credentials and regulatory claims before publishing. Google Fonts requires an internet connection; system fallbacks are provided.
